My GitHub Pages home page.

Change the content between the "EDIT FREELY" comments as you like. **Keep the script at the bottom.** It forwards people back to the app they came from after they install the GitHub App on a repo (see [github-auth-relay](https://github.com/barton-muller/github-auth-relay)). On normal visits it does nothing.
